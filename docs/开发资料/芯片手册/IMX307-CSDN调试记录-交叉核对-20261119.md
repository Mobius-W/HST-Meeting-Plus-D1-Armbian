## 该文最终配置

## ★ 与本板（RK3399-mid）交叉核对 — 全部吻合

| CSDN 标准值/结论 | 本板实测/配置 | 吻合 |
|---|---|---|
| 输入 MCLK 37.125MHz | `clk_cifout=37125000 Y`，xvclk→4-001a | ✅ |
| CSI-2 2 lane | DTS endpoint `data-lanes=<1 2>` | ✅ |
| RAW10 | 灌表 0x3009=0x02（原厂表值）；cam_board.xml SensorFmt=Raw_10b | ✅ |
| 1080p@30fps | 实测 30.00fps、60 帧 1920×1080×2 | ✅ |
| `op_pixel_clk`/link-freq = **222.75MHz** | DTS `link-frequencies=<222750000>` | ✅ |
| `frame_length_lines=1125`(0x465) | 灌表 0x3018/19=0x65/0x04 = 0x0465 | ✅ |
| IMX327 无专用 ID 寄存器，用普通寄存器默认值当 id | 本板 0x301E=0xb2 作 chip_id 匹配 | ✅ |
| vt_pixel_clk = line_length×frame_length×fps | 本板 mainline 驱动按此算曝光（见 imx307.c） | ✅ |

> `line_length_pclk` 本板回读 0——mainline 驱动不显式配此寄存器即可出帧（已 30fps 闭环），非卡点。

## 价值
独立平台（高通）的同族 sensor 调试记录，**交叉印证** Sony flyer + 原厂 cam_board.xml/vendor 驱动挖出的参数全部正确。至此 IMX307 参数有四条独立证据链：Sony 官方 flyer、原厂 Android cam_board.xml、vendor 4.4 驱动、本篇高通平台博客。摄像头出图已闭环（见 `camera/IMX307-EPIPE-根因-20261117.md` §七），本篇仅作参数背书，无新寄存器线索。
